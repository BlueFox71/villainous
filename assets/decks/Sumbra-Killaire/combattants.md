# Combattants Sumbra / Killaire — table (2026-07-17)

Deck **commun** de Combattants. Chaque carte porte **☀️ (Killaire)** et **🌑 (Sombra)**, échelle **1-4, min 1**.
Camp = royaume World of Light (Lumière→Killaire, Ténèbres+sous-mondes→Sumbra). Roy/Palutena/Kirby = Killaire ; Dark Samus/Bayonetta = Sumbra ; tous les DLC → Sumbra (équilibrage).

## Résolution à la pioche
1. **Capture** [ta valeur d'esprit courante : ☀️ si Killaire, 🌑 si Sombra].
2. **Alignement** (ta valeur vs adverse) → **aligné = Bonus** du verbe / **désaligné = Malus** / égalité = rien.

## Verbes (6) — signe décidé par l'alignement
- ⚡ **Décharge** : ±N Pouvoir
- 🌟 **Ferveur** : ±N esprits (direct jauge ; fort → rare, grosses cartes)
- 🃏 **Renfort** : Bonus = au choix pioche N cartes Méchant **ou** récupère 1 carte de ta défausse · Malus = défausse N
- 🛡️ **Rempart** : ±N Force d'un de tes lieux
- 🔁 **Surtension** : Bonus = pioche +1 Combattant ce tour · Malus = le prochain ne marque pas *(magnitude fixe : +1)*
- 💠 **Aubaine** : Bonus = tes cartes coûtent N jetons Pouvoir de moins ce tour · Malus = N de plus

Magnitude par palier : **Légende** = fort (Ferveur 2 / Décharge 3 / Rempart 3) · **Standard** = moyen (N 2, Ferveur/Renfort/Aubaine 1) · **Novice** = faible (N 1).

Total : 74 base + 12 DLC = **86**. Camps : Killaire **45** / Sumbra **41**.

COMBATTANTS SUMBRA / KILLAIRE — table (2026-07-17)
=====================================================

Deck commun. Chaque carte porte ☀️ (Killaire) et 🌑 (Sombra), echelle 1-4, min 1.
Camp = royaume World of Light (Lumiere->Killaire ; Tenebres+sous-mondes->Sumbra).
Roy/Palutena/Kirby = Killaire ; Dark Samus/Bayonetta = Sumbra ; tous DLC -> Sumbra.

RESOLUTION A LA PIOCHE
  1. Capture [ta valeur d'esprit courante : ☀️ si Killaire, 🌑 si Sombra].
  2. Alignement (ta valeur vs adverse) -> aligne = Bonus / desaligne = Malus / egalite = rien.

VERBES (6) — signe decide par l'alignement
  ⚡ Decharge : ±N Pouvoir
  🌟 Ferveur  : ±N esprits (direct jauge ; fort -> rare)
  🃏 Renfort  : Bonus = au choix pioche N cartes Mechant OU recupere 1 carte de ta defausse ; Malus = defausse N
  🛡️ Rempart  : ±N Force d'un de tes lieux
  🔁 Surtension: Bonus = pioche +1 Combattant ce tour ; Malus = le prochain ne marque pas (magnitude fixe +1)
  💠 Aubaine  : Bonus = tes cartes coutent N jetons Pouvoir de moins ce tour ; Malus = N de plus

Magnitude par palier : Legende fort (Ferveur 2 / Decharge 3 / Rempart 3) | Standard moyen (2, sinon 1) | Novice faible (1).
Total : 74 base + 12 DLC = 86.  Camps : Killaire 45 / Sumbra 41.

Format : ☀️/🌑

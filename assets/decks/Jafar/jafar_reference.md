# Jafar — données de jeu (transcription depuis les images du deck, FR)

Source : `assets/decks/Jafar/*.png` (deck Tabletop Simulator, français).

## Objectif
**Au début de votre tour, la LAMPE MERVEILLEUSE doit se trouver au Palais du Sultan
et le GÉNIE doit être sous HYPNOSE (sous votre contrôle).**

## Plateau (4 lieux, gauche → droite ; rangées haut / bas)
Icônes : jeton = Gagner pouvoir · carte+△ = Jouer · carte+rayons = Fatalité ·
cartes+X = Défausser · carte+◁▷ = Déplacer objet/allié · étoile = Vaincre ·
nuage+éclair = Déplacer un héros.

- **Palais du Sultan** — haut: Jouer · Fatalité | bas: Vaincre · Déplacer un héros
- **Rues d'Agrabah** — haut: Gagner 1 · Déplacer un héros | bas: Défausser · Jouer
- **Oasis** — haut: Fatalité · Jouer | bas: Gagner 3 · Jouer
- **Caverne aux Merveilles** (VERROUILLÉE au départ) — haut: Défausser · Gagner 2 | bas: Jouer · Déplacer objet/allié
